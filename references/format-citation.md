# REFERENCE — Format de Citation

**Version** : 4.1.8 | **Objectif** : Normaliser les citations juridiques

---

## Principes Généraux

### Règles de Base

1. **Précision** : Chaque élément doit être exact et vérifiable
2. **Complétude** : Toutes les informations nécessaires doivent être présentes
3. **Cohérence** : Utiliser le même format dans tout le document
4. **Traçabilité** : Pouvoir vérifier chaque référence

### Éléments Obligatoires

| Type | Éléments |
|------|----------|
| Article de code | Code, numéro d'article, version |
| Jurisprudence | Juridiction, date, numéro, source |
| Texte européen | Type, numéro, titre, date |
| Doctrine | Auteur, titre, revue, année |

## Citation des Textes Législatifs

### Code Français

**Format**
```
Code {nom du code}, art. {numéro}
Code {nom du code}, art. {numéro} à {numéro} (plage)
Code {nom du code}, art. {numéro}, al. {n}
```

**Exemples**
```
Code civil, art. 1101
Code du travail, art. L. 1234-1
Code de la consommation, art. L. 212-1, al. 2
Code pénal, art. 221-6 à 221-11
```

### Lois et Décrets

**Format**
```
Loi n° {YYYY}-{NNNN} du {date}, {intitulé}
Décret n° {YYYY}-{NNNN} du {date}
Arrêté du {date}
```

**Exemples**
```
Loi n° 2019-222 du 23 mars 2019 de programmation 2018-2022
Décret n° 2020-1234 du 9 octobre 2020 relatif à...
Arrêté du 15 décembre 2020 fixant le taux...
```

### Textes Européens

**Format**
```
Règlement (UE) n° {YYYY}/{XXXX}/{XXX}
Directive {YYYY}/{XX}/CE
Décision {YYYY}/{XX}/CE
Traité sur le fonctionnement de l'Union européenne (TFUE)
```

**Exemples**
```
Règlement (UE) 2016/679 du 27 avril 2016 (RGPD)
Directive 2005/29/CE du 11 mai 2005 relative aux pratiques commerciales déloyales
Charte des droits fondamentaux de l'UE, art. 47
```

## Citation de la Jurisprudence

### Juridictions Judiciaires

#### Cour de Cassation

**Format de base**
```
{Cour}, {Chambre}, {date}, n° {numéro de pourvoi}
```

**Format complet**
```
{Cour} {Chambre}, {date}, n° {numéro de pourvoi}
Source : {Bull. civ., Lebon, Inédit}
[Réf. Légifrance : {lien LEGIARTI}]
```

**Exemples**
```
Cass. Civ. 1re, 15 juin 2022, n° 21-12.345
Cass. Com., 10 mars 2021, n° 19-18.234
Bull. civ. I, n° 123

Cass. Soc., 11 mai 2010, n° 09-42.241
Rec. Lebon, Tables

Cass. Crim., 5 janv. 2023, n° 22-82.123
Inédit
```

#### Formation Solennelle

| Formation | Format | Usage |
|-----------|--------|-------|
| Assemblée plénière | `Ass. plén.` | Questions de droit nouvelles |
| Chambre mixte | `Ch. mixte` | Conflit entre chambres |
| Chambres réunies | `Ch. réunies` | Révision de jurisprudence |

**Exemple**
```
Ass. plén., 9 mai 1984, n° 80-14.994
```

#### Tribunaux Inférieurs

**Format**
```
Tribunal {type}, {ville}, {date}, n° {numéro}
```

**Exemples**
```
Tribunal judiciaire de Paris, 15 mars 2023, n° 22/12345
Conseil de prud'hommes de Lyon, 10 janv. 2023, RG n° F23/00123
```

### Juridictions Administratives

#### Conseil d'État

**Format**
```
CE, {date}, n° {numéro de requête}
Source : {Lebon, Tables, Inédit}
```

**Exemples**
```
CE, 12 mars 2021, n° 438749
Lebon

CE, 21 févr. 2020, n° 434402
Tables
```

#### Cours Administratives d'Appel

**Format**
```
CAA {ville}, {date}, n° {numéro}
```

**Exemple**
```
CAA Paris, 5 avr. 2022, n° 20PA01234
```

#### Tribunaux Administratifs

**Format**
```
TA {ville}, {date}, n° {numéro}
```

**Exemple**
```
TA Marseille, 3 mars 2023, n° 2101234
```

---

### Juridictions Européennes

#### CJUE

**Format**
```
CJUE, {date}, C-{numéro}, {nom}
```

**Exemples**
```
CJUE, 6 oct. 2021, C-123/20, Name
CJUE, 15 avr. 2021, C-511/18, Name
```

**Conclusions de l'Avocat général**
```
Conclusions de l'Avocat général {nom}, {date}, affaire C-{numéro}
```

#### CEDH

**Format**
```
CEDH, {date}, req. n° {XXXXX}/{XX}, {nom} c. {Pays}
```

**Exemples**
```
CEDH, 21 oct. 2021, req. n° 12345/19, Name c. France
CEDH, 15 sept. 2020, req. n° 5678/17, Name c. France
```

## Citation de la Doctrine

### Principe

> La doctrine est **toujours** présentée entre parenthèses et distinguée du droit positif.

### Format

**Article de revue**
```
({Auteur}, « {Titre de l'article} », {Revue}, {Année}, {page})
```

**Ouvrage**
```
({Auteur}, {Titre de l'ouvrage}, {Éditeur}, {Année}, n° {para})
```

**Chronique**
```
({Auteur}, « {Titre} », {Revue}, {Année}, {page})
```

### Exemples

```
(Compte-tenu de : Malaurie, Aynès, Stoffel-Munck, Les obligations, Defrénois, 2022, n° 234)
(François Terré, « Pour une réforme du droit des obligations », D. 2017, p. 123)
(Voir aussi : Jean Carbonnier, Droit civil, PUF, 2004, t. 4, § 45)
```

## Citation dans les Actes Juridictionnels

### Assignation / Requête

**Format recommandé**
```
Code {nom}, art. {numéro} {extrait pertinent entre guillemets si nécessaire}
```

**Exemple**
```
Code du travail, art. L. 1234-1 : « Toute rupture du contrat de travail
résulte soit du consentement des parties, soit de la volonté patronale... »
```

### Conclusions

**Format recommandé**
```
{Cour} {Chambre}, {date}, n° {numéro} (cite in {Bull./Lebon})
{synthèse de la solution}
```

## Traçabilité des Citations

### Règle d'Or

> **Chaque citation doit être vérifiable. Si vous ne pouvez pas vérifier, marquez `[NON VÉRIFIÉ]`.**

### Exemple d'Application

```
✅ Correct :
« L'article L. 1234-1 du Code du travail dispose... »
Cass. Soc., 11 mai 2010, n° 09-42.241 (Legifrance : LEGIARTI...)

❌ Incorrect :
« L'article L. 9999-1 du Code du travail... » (inventé)

⚠️ Avec vérification impossible :
« L'article L. 1234-1 du Code du travail... » [NON VÉRIFIÉ — à confirmer sur Légifrance]
```
