# Adaptateur Perplexity

Perplexity accepte l'archive de release contenant `SKILL.md` a la racine. Ce
fichier commence par un frontmatter YAML avec `name` et `description`, exigé par
le chargeur de skills. Televerser l'archive attachee a une release GitHub, pas
le ZIP automatique de la page `Code`, qui ajoute un repertoire parent.

Lorsque les Spaces, instructions personnalisees ou pieces jointes sont
disponibles, les utiliser comme correspondance documentaire et non comme une
preuve que les documents ont ete consultes.

Placer `core/system-prompt.md` dans la surface d'instructions puis fournir la
methodologie, le registre, le profil et les domaines pertinents. Les citations
Perplexity doivent encore etre controlees quant au type, a la version, a la date
et a l'applicabilite de la source.
