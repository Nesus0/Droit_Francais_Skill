# Adaptateur Gemini

Les surfaces Gemini peuvent proposer des instructions personnalisees et des
fichiers. Utiliser `core/system-prompt.md` comme instructions, puis joindre la
methodologie, le registre, le profil et les domaines lorsque le produit choisi
prend ce flux en charge.

Les outils, le grounding et la disponibilite des fichiers dependent du produit
et de la configuration. Appliquer le protocole d'acces degrade lorsqu'une source
ne peut pas etre verifiee dans l'interaction.
