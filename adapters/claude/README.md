# Adaptateur Claude

Claude Code peut utiliser `SKILL.md` depuis un repertoire de competences
correctement installe; les autres produits Claude peuvent n'accepter que des
instructions de projet ou des documents joints.

Pour Claude Code, copier le depot dans le repertoire choisi en conservant
`SKILL.md` et tous les fichiers references. Pour les autres surfaces, mapper
`core/system-prompt.md` aux instructions du projet et fournir la methodologie,
le registre, le profil et les domaines utiles.

Verifier la documentation du produit avant d'affirmer qu'une source est
accessible ou consultable.
