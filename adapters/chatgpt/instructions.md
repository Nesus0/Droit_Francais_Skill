# Correspondance des instructions ChatGPT

1. Copier le contenu complet de `core/system-prompt.md` dans Instructions.
2. Ajouter `core/methodology.md`, `references/sources.json`, le profil choisi et
   les domaines pertinents dans Connaissances, si cette fonction est disponible.
3. Activer uniquement la navigation ou les Actions effectivement prises en
   charge par le compte.
4. Tester le comportement lorsque les sources sont indisponibles : marquer
   `[NON VERIFIE]`, ne pas inventer de precision et fournir un parcours officiel.
